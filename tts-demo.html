🔊 日语 TTS 对比 Demo

输入日语文本，点击各引擎的播放，对比音质。Web Speech 与 Kokoro 无需安装；VOICEVOX、Edge 需要本地小程序（下方有说明，页面会自动检测是否在运行）。

1. Web Speech API 检测中…

浏览器内置，免费、即时、离线。音质较旧，依赖系统日语语音（macOS「Kyoko」）。无音高重音控制。

2. Kokoro-82M（浏览器内 / WebGPU·WASM） 仅英文

⚠️ 结论：kokoro-js 浏览器版只内置英文语音 + 英文音素化，不支持日语（无 jf_/jm_ 音色，也没有日语 G2P）。下面用一句英文试听，仅用于确认模型能在浏览器跑——它不适合本应用的日语场景。首次会下载模型（约 80–330 MB，之后缓存）。

3. VOICEVOX（本地引擎） 检测中…

专为日语打造的开源引擎，音质与自然度最佳，支持音高重音。需在本机运行 VOICEVOX 引擎（端口 50021）。
如何启动 VOICEVOX 
1) 下载安装 VOICEVOX：https://voicevox.hiroshiba.jp/
2) 打开 VOICEVOX 应用（它会在 http://localhost:50021 提供引擎 API）。
   或仅运行引擎：下载 voicevox_engine，运行 run（默认 50021）。
3) 回到本页点「检测/播放」。若浏览器报跨域(CORS)，
   用引擎参数 --cors_policy_mode all 启动。

4. Edge TTS（微软在线语音，经本地代理） 检测中…

微软神经语音（Nanami/Keita），接近商用音质，体积极小、免费。非开源，需联网，并经一个本地代理避开浏览器跨域。
如何启动 Edge 代理 
pip install edge-tts
python3 tools/edge_proxy.py     # 监听 http://localhost:5050
# 然后回到本页点播放
